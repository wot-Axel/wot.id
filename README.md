# wot.id

wot.id is a robust, decentralized identity and credential mapping system designed for unique human users. It leverages Ethereum, Optimism L2, and on-chain attestations for secure, auditable, and upgradeable identity management.

## 📜 Design Principles

The core design principles for wot.id are documented in detail in [docs/wotid_design_principles.md](docs/wotid_design_principles.md). **Please read them first if you are contributing, auditing, or using this project.**
